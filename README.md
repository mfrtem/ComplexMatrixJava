# Матрицы комплексных чисел на Java

Практическая работа № 1. Программа для работы с матрицами, элементы которых являются комплексными числами.

## Возможности

- Создание матриц комплексных чисел
- Сложение матриц с сохранением результата в матрице A
- Умножение матриц с сохранением результата в матрице A
- Деление матриц, если оно возможно, с сохранением результата в матрице A
- Транспонирование матрицы A с сохранением результата
- Вычисление определителя текущей матрицы A
- Просмотр текущего состояния матрицы A
- Обработка ошибок при выполнении операций
- Консольный интерфейс для создания матриц и выбора операций

- Java JDK 21 или новее

## Запуск программы

Откройте терминал в корневой папке проекта и выполните команды:

```bash
javac src/*.java
java -cp src Main
```

## Работа с программой

После запуска программы появляется консольное меню со следующими пунктами:

1. Создать матрицу A — ввести размеры матрицы и значения её элементов.
2. Создать матрицу B — ввести вторую матрицу.
3. Сложить матрицы A и B — результат сохраняется в A.
4. Умножить матрицы A и B — результат сохраняется в A, если размеры матриц позволяют выполнить операцию.
5. Разделить матрицу A на матрицу B — результат сохраняется в A, если деление возможно.
6. Транспонировать матрицу A — поменять строки и столбцы местами и сохранить результат в A.
7. Вычислить определитель матрицы A — найти определитель текущей матрицы A.
8. Показать матрицу A — вывести её текущее состояние.
0. Выход — завершить работу программы.

### Сохранение результатов

Матрица A используется для хранения текущего результата вычислений. После сложения, умножения, деления или транспонирования результат сохраняется в A и может использоваться в следующих операциях.

Матрица B остаётся неизменной и может повторно использоваться в вычислениях. Вычисление определителя не изменяет матрицу A.

### Ввод элементов

Для создания матрицы необходимо указать количество строк и столбцов. Затем для каждого элемента вводятся две величины:
- действительная часть;
- мнимая часть.

Например, для комплексного числа `3 + 2i` нужно ввести `3` и `2`.

После выполнения операции программа выводит результат в консоль и возвращается к главному меню.

Перед выполнением операции необходимо сначала создать все матрицы, которые она использует.

Если операция невозможна, например матрицы имеют неподходящие размеры или матрица B не имеет обратной матрицы, программа выводит сообщение об ошибке.
